## **공학용 계산기 프로그램**
**핵심 기능**
1. 삼각함수 기능
- sin, cos, tan 연산 기능으로, 괄호 안에 입력하는 수를 라디안값으로 치환하여 계산합니다.
2. log, sqrt 기능
- log와 제곱근 연산 기능으로, 괄호 안에 입력하는 수의 log 값과 제곱근 값을 각각 계산합니다.
3. 괄호 기능
- 괄호 안에 입력되는 식은 우선 순위로 계산합니다.
4. 기타 불편 사항 개선
- 키보드 입력을 지원하지 않아 클릭으로만 가능했던 계산기 사용을 더욱 편리하게 개선하였습니다. 숫자 및 기본 연산자(+,-,( 등)는 키보드로도 입력이 가능하게 했습니다.
- 백스페이스 키를 이용한 지우기 기능, 엔터 키를 이용한 결과 계산하기 기능을 추가했습니다.
